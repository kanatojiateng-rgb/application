## App Name
本アプリは、個人の支出データを分析し、支出傾向の可視化と節約額の投資シミュレーションを行う資産形成応援
webアプリです。
家計管理だけでなく、「節約　→　投資　→　将来資産の可視化」までを一貫して行うことを目的としています。

## Features
- 支出の登録
- 月次・年間支出傾向の把握
- 節約額の算出
- 複利計算による将来資産形成シミュレーション

## Invsetment Simulation
年間節約額を一定利回りで複利運用した場合の将来資産額をシミュレーションします。

## Tech stack
Frontend： HTML/css/JavaScript
Backend : flask(Python)
Database : SQlite
ORM : SQLalchemy
